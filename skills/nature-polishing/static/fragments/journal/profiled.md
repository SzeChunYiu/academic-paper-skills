# Profiled target journal — polishing

Use this fragment when the target is a named journal outside the repository's exact Nature profiles, a publisher/venue family such as Science/AAAS, Cell Press, IEEE, ACM, PLOS, Springer/BMC, Elsevier, or Wiley, or when the manuscript is being transferred between journals.

Before applying journal-specific edits, read:

1. `../../../../nature-shared/journal-formats/journal-resolution.md`
2. `../../../../nature-shared/journal-formats/journal-family-profiles.md`

Resolve `exact journal -> article/content type -> stage -> component` before enforcing house rules.

## Polishing contract

Polish in two passes.

### Pass A — target-independent scientific edit

Fix clarity, paragraph logic, terminology consistency, claim/evidence alignment, causal overreach, redundant statistics, undefined abbreviations, awkward syntax, and unnecessary repetition. Preserve facts, uncertainty, limitations, citation intent, and technical meaning.

### Pass B — target-dependent adaptation

Only after the target is resolved, adapt:

- audience breadth and assumed background
- title/abstract compression and framing
- section and heading conventions
- terminology/abbreviation density
- main-text versus Methods/Supplementary allocation
- reference/display economy
- required front/back matter wording

Do not import another journal's punctuation, reference style, legend limit, title limit, or submission mechanics because the journals share a publisher.

## Journal-transfer mode

When moving a manuscript from journal A to journal B:

1. Preserve target-independent scientific edits.
2. Remove A-only house style and submission boilerplate.
3. Resolve B's exact article type and stage.
4. Re-apply only B-supported constraints.
5. Run a consistency sweep after the transfer so abbreviations, section references, figure/table mentions, declarations, and supplementary references remain coherent.

If an exact rule cannot be verified, mark it `unresolved` instead of silently applying a family convention.
